## Getting Started

**Welcome to the VS Code Java World!**
This guide will help you set up and start writing Java code in Visual Studio Code (VS Code). Whether you’re building small projects or larger applications, this setup ensures a smooth development experience.

## Folder Structure
Your workspace is organized into the following default folders:

- `src/` → contains your Java source files (.java)

- `lib/` → stores external libraries and dependencies

- `bin/` → automatically generated folder that stores compiled .class files

You can customize this structure by editing .vscode/settings.json to match your project’s needs.  
Meanwhile, the compiled output files will be generated in the `bin` folder by default.

> If you want to customize the folder structure, open `.vscode/settings.json` and update the related settings there.

## Running Your Code
1. Open any .java file inside the src/ folder.
2. Click Run ( ▶ ) in the top-right corner of the editor, or use the shortcut:
   - Windows/Linux: Ctrl + F5
   - Mac: Cmd + F5
3. Compiled class files will be stored in the bin/ folder automatically.

## Dependency Management

The `JAVA PROJECTS` view allows you to manage your dependencies. More details can be found [here](https://github.com/microsoft/vscode-java-dependency#manage-dependencies).
